这个插件通过亚马逊的销售伙伴 API（SP-API）把 cx 连接到你自己的亚马逊店铺。连接店铺后，cx 可以读取你的订单、Listing、库存、报告和财务数据，并在你授权的站点内进行修改，比如更新 Listing 或价格。

你可以这样问：

- 今天来了多少订单？哪些还在等待处理或已取消？
- 我的哪些 FBA Listing 会在两周内断货？
- 这个 Listing 有什么问题，要怎么修复？

## 连接店铺

打开插件的「设置」，为你开店的每个区域连接一个店铺：北美、欧洲或远东。亚马逊的自授权指南说明了在哪里找到「设置」需要填写的内容。你的密钥保存在 ComChatX 平台上，不会交给 cx。

## 费用

免费。亚马逊和 ComChatX 都不对 SP-API 调用收费。

## 依赖

它会和 cx-sources 一起安装，cx 通过 cx-sources 使用所有数据源。
