把你的亚马逊店铺连到 cx，cx 就能读你卖家后台里的订单、listing、库存、报告和财务数据，也能替你修改。它能按站点汇总订单和销售额，找出快断货的 FBA 商品和被亚马逊标出问题的 listing，查清每笔交易扣了哪些费用，并替你修改 listing 和价格。适合每天看销量、查费用、处理 listing 的问题。连接用的是 SP-API，亚马逊给卖家工具开放的官方接口，覆盖你在北美、欧洲和远东授权的站点。

你可以这样问：

- B0EXAMPLE1 上周的流量和转化率是多少？
- 把 B0EXAMPLE1 在美国站的价格改成 24.99 美元。
- 上个月的货款里，亚马逊扣了哪些费用？

## 连接店铺

在插件的「设置」里，为你开店的北美、欧洲或远东区域各连接一个店铺。要填的内容在哪里找，见亚马逊的自授权指南。你的密钥保存在 ComChatX，不会交给 cx。

## 费用

免费，亚马逊和 ComChatX 都不收费。
